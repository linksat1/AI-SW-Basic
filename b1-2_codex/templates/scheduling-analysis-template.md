## 3. Pattern Analysis (패턴 분석)

| 후보 알고리즘 | 판단 | 근거 |
|---|---|---|
| FCFS | 해당/비해당 | 먼저 온 작업이 끝까지 실행되었는지 확인 |
| Round-Robin | 해당/비해당 | 여러 작업이 시간 조각처럼 번갈아 실행되었는지 확인 |
| Priority | 해당/비해당 | 특정 작업이 우선적으로 반복 실행되었는지 확인 |

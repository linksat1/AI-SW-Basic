Mini Git 실행·검증·평가 발표 자료

저장 위치: AI-SW-Basic/b3-2/제출/발표자료/

1. MiniGit_실행검증_평가설명.pptx
   26장, 편집 가능한 텍스트·도형. 슬라이드마다 발표자 노트가 있습니다.
   각 슬라이드의 도표·본문 배치와 여백을 조정하고,
   해당 페이지 하단에 설명노트 전체를 넣었습니다. PDF에서도 읽을 수 있습니다.
   기능별 페이지에는 실행 명령과 기대 결과를 추가했습니다.
   'mini-git>' 표시는 프로그램 안에서, '일반 터미널' 표시는 b3-2 폴더에서 실행합니다.
   화살표로 연결된 명령은 한 줄씩 따로 입력합니다.
   각 실습은 독립 예시입니다. '5페이지 실습 후'는 5페이지의 INIT부터 재현한 상태입니다.
   INIT은 기존 세션 데이터를 초기화합니다. hash는 현재 LOG의 값으로 교체하세요.
   선택 테스트의 -k 옵션은 해당 이름이 포함된 검사만 실행합니다.
   PowerPoint의 보기 > 노트 또는 발표자 도구에서 노트를 확인하세요.
   01~10장: 실행·검증·증거 위치,
   11~21장: 원리 설명, 22~26장: 평가 답변·요약.

2. MiniGit_실행검증_평가설명.pdf
   PPT와 같은 콘텐츠·레이아웃의 읽기용 자료입니다. 발표자 노트는 포함하지 않습니다.
   발표자_설명노트.txt의 설명 전체를 본문에 포함합니다.
   PDF·미리보기는 동일한 레이아웃 데이터로 별도 렌더링한 것이며,
   PowerPoint 앱의 출력 화면을 캡처한 것은 아닙니다.

3. 발표자_설명노트.txt
   초보자용 비유·용어·답변 연습·주의점을 원본 26장 번호로 읽을 수 있습니다.

4. 전체슬라이드_미리보기.png / 미리보기/
   전체 목차 이미지와 각 장의 미리보기입니다.

5. 발표자료_검증결과.json / 과제_재검증.txt
   PPTX ZIP·XML·내부 연결과 26개 노트, 배치 범위·텍스트 겹침·잘림을 확인했습니다.
   과제 테스트는 Python 3.12.13에서 15개 모두 통과했습니다.
   PowerPoint 앱을 직접 실행해 렌더링한 결과는 포함하지 않습니다.

6. Figma 편집본
   이 대화의 Figma 발표 자료 미리보기를 선택해 찾아볼 수 있습니다.
   PPTX는 같은 검증된 콘텐츠로 별도 작성한 파일이며 Figma에서 내보낸 파일은 아닙니다.

실습 시작 (실제 프로젝트 경로가 다르면 cd 경로를 바꾸세요)
   cd ~/AI-SW-Basic/b3-2
   python3 --version       (3.10 이상 확인)
   python3 main.py

검증 재현 (Mini Git에서 exit로 종료한 다음 터미널에 입력)
   python3 -B -m unittest discover -s tests -v
   성공 기준: Ran 15 tests / OK

증거 위치 (b3-2 기준)
   tests/test_mini_git.py             검사 소스
   제출/results/11_자동검증.txt        검사 원본 기록
   제출/results/10_보완_회귀검증.txt    수정된 동작 기록
   제출/실행결과.md                   결과 요약
   최종검수결과.md                    과제 요구사항 대조
   mini_git/                         실제 구현

실습할 때 hash 자리 표시자는 화면에 나온 실제 값으로 바꿉니다.
Merge 명령은 구현하지 않았으며 다중 부모 그래프는 테스트에서 직접 구성합니다.
단어 검색은 토큰 전체, 여러 단어는 연속 구문을 찾습니다.
PPT의 도형 A/B/C/D와 고정 hash는 개념 설명·테스트 예시입니다.

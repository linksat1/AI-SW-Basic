## 학습 목표와 문서

[평가질문_설명자료.md](평가질문_설명자료.md)에 DAG, 부모 우선 로그,
최단 경로·조상 탐색, 병합 정렬의 평균·최악 O(n log n)과 안정성,
역색인 조회 원리를 설명했습니다. 이는 설명 자료의 구비 여부를 확인한 것이며,
학습자의 구두 설명 능력 자체를 평가한 결과는 아닙니다.

- 부모 참조는 자식→부모입니다. LOG는 간선을 부모→자식으로 뒤집은 그래프에
  Kahn 알고리즘을 적용하므로 부모 수를 진입차수로 사용합니다.
- ANCESTORS는 인덱스 큐와 방문 집합으로 O(V+E)입니다.
- 단어·작성자 색인 조회는 평균 O(1)이며 결과 복사는 O(k)입니다.
  검색어 정규화·해싱 비용은 입력 길이에 따라 추가됩니다.
- 구문 검색은 가장 드문 단어의 후보 메시지만 검사합니다. 구문 길이 q,
  후보 메시지 토큰 수 합 T에 대해 후보 검사 비용은 최악 O(T·q)입니다.
  구문 검색을 항상 O(1)이라고 설명하지 않습니다.
- 카운터가 서로 다른 hash 출력을 보장하지는 않습니다. 유일성은 기존 hash
  검사와 재시도가 보장합니다. 현재 6자리 hash 공간은 16**6개로 유한합니다.

## 범위와 한계

구문 검색은 연속된 단어의 순서·반복 횟수를 구분하며, 대소문자와 공백 수를
무시합니다. 부분 문자열 검색은 구현하지 않습니다. 작성자 이름은 정확히 일치해야 합니다.
CLI는 INIT에서 설정한 작성자로 커밋하므로 서로 다른 작성자의 정렬은 테스트에서
커밋 데이터를 구성해 검증합니다.

Diff, Merge 명령, 정렬 알고리즘 성능 비교는 선택 과제로 구현하지 않았습니다.
병합 커밋 탐색 검증은 테스트가 직접 구성한 다중 부모 그래프를 사용합니다.
이 검수는 과제 범위와 포함된 테스트에 대한 결과이며 임의의 모든 입력에 대한
무결함을 증명하는 것은 아닙니다.

# CLI 옵션 (model / max-tokens / effort / temperature / safe-mode)
$ python3 ./main.py describe --help

usage: main.py describe [-h] [--intent INTENT] [--no-input] [--model MODEL]
                        [--max-tokens MAX_TOKENS]
                        [--effort {low,medium,high,xhigh,max}]
                        [--temperature TEMPERATURE] [--safe-mode]
                        [--max-files MAX_FILES]
                        [--max-diff-lines MAX_DIFF_LINES]
                        [--mask-pattern REGEX] [--convention PATH] [--mock]
                        [--dry-run]

options:
  -h, --help            show this help message and exit
  --intent INTENT, -i INTENT
                        수정 의도/요약 (생략하면 대화식으로 입력)
  --no-input            대화식 입력을 건너뜁니다.

AI API 파라미터:
  --model MODEL         모델 ID (기본: claude-opus-5-5)
  --max-tokens MAX_TOKENS
                        최대 출력 토큰, 사고 토큰 포함 (기본: 16000)
  --effort {low,medium,high,xhigh,max}
                        추론 노력 수준 (기본: low)
  --temperature TEMPERATURE
                        샘플링 온도 (기본: 미전송. 현재 API 버전/기본 모델은 지원하지 않음)

safe-mode / 컨벤션:
  --safe-mode           민감정보 마스킹 + diff 전송량 제한
  --max-files MAX_FILES
                        safe-mode 전송 최대 파일 수 (기본 10)
  --max-diff-lines MAX_DIFF_LINES
                        safe-mode 전송 최대 diff 줄 수 (기본 200)
  --mask-pattern REGEX  safe-mode 추가 마스킹 정규표현식 (여러 번 지정 가능)
  --convention PATH     컨벤션 JSON 경로 (기본: 저장소 루트의 .ai-code-summary.json)

실행 모드:
  --mock                API 호출 없이 데모 응답으로 흐름을 확인합니다.
  --dry-run             AI로 보낼 프롬프트만 출력하고 종료합니다.

(exit code: 0)

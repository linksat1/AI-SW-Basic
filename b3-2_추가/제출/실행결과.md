# B3-2 추가 과제 — 실행 결과 제출자료

2026-11-01, **Python 3.12.13**과 **anthropic 2.3.0**으로 실행한 결과입니다(과제 환경: Python 3.10 이상).
결과 파일은 `bash 제출/make_results.sh <python>`으로 다시 만들 수 있습니다. 이 스크립트는 임시 Git 저장소를 만들고,
세션 모듈 수정, 가짜 비밀값이 든 `config.py`, 핸들러 파일 12개로 총 14개 파일 변경을 준비한 뒤 각 시나리오를 실행합니다.
결과에 나오는 키, 이메일, 전화번호는 모두 시연용 가짜 값입니다.

## 실제 API 확인

- 정상 생성: 실제 API를 1회 호출해 이번 변경의 설명문을 생성하고 형식 검증을 통과했습니다(11).
- 오류 처리: 잘못된 키로 호출해 실제 401 응답이 원인 메시지로 출력되는 것을 확인했습니다(04).
- 재현 스크립트: `make_results.sh`는 비용이 들지 않도록 API Key를 해제하고 실행합니다. 그래서 정상 흐름(02)은 `--mock`으로, 형식 오류 → 재생성 → 보정(08)은 응답을 바꿔 끼운 시뮬레이션으로 확인합니다.

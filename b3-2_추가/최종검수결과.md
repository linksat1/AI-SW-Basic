## 5. 이전 검수에서 지적된 항목 처리

| 지적 사항 | 조치 |
|---|---|
| SDK 예외 미처리로 traceback 출력 | 예외 클래스별 원인 메시지로 변환, 실제 401 응답 확인 |
| 검증 실패 시 재생성/후처리 없음 | 피드백 재생성 1회 + 후처리 보정 |
| GitHub 미push | 브랜치에 커밋 완료, push는 사용자 확인 후 진행 |
| mock 모드가 `--intent` 무시 | mock 응답이 실제 변경 파일, 수정 의도, 컨벤션을 반영 |
| 새 파일이 diff에서 누락 | `git diff --no-index`로 수집 |
| 단계별 `[INFO]` 로그, 호출 횟수 없음 | 추가 |
| temperature 기본값 `None` | 현재 API가 temperature를 거부하므로 기본은 보내지 않음으로 두고 `--effort`(기본 low)로 품질을 조절. README에 근거 설명 |
| 기본 모델 ID 불확실 | `claude-opus-5-5`로 변경 |
| 50자 권장 기준 미검사 | 경고로 검사 |
| README 출력 예시 글자 수 오류 | 실제 출력 형식으로 다시 작성 |
| `제출/` 비어 있음 | 실행 결과 11개, 결과 생성 스크립트, 보너스 문서 추가 |
| (실제 실행에서 발견) 하위 불릿까지 개수에 셈 | 최상위 불릿만 세도록 수정, 테스트 추가 |

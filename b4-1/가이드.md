## 1. 과제 개요

**만들어야 하는 것**: 나만의 포트폴리오 웹사이트

**사용하는 기술**: HTML, CSS, JavaScript만 (React, jQuery 등 외부 라이브러리 사용 금지)

**완성 기준**:
- [ ] 반응형 웹사이트 (모바일/태블릿/데스크톱 모두 정상 표시)
- [ ] 다크 모드 토글 (새로고침 후에도 설정 유지)
- [ ] 햄버거 메뉴 (모바일에서 작동)
- [ ] 부드러운 스크롤 + 스크롤 탑 버튼
- [ ] GitHub API 연동 (내 저장소 목록 자동 표시)
- [ ] 폼 유효성 검사 (빈 칸, 이메일 형식 검사)
- [ ] GitHub Pages 배포 (외부 접속 가능한 URL)

**폴더 구조**:
```
portfolio/
├── index.html        ← 메인 HTML (여기서 시작)
├── css/
│   └── style.css     ← 스타일
├── js/
│   └── main.js       ← JavaScript 기능
├── images/
│   └── profile.jpg   ← 프로필 사진
└── README.md
```

## 3. 내 정보로 수정하기

> 교본 파일에 이미 작성된 내용이 있지만 **일부 값이 잘못 설정된 상태**입니다.
> 아래 순서대로 수정하세요.

### 3-1. `js/main.js` — GitHub 사용자명 수정 (중요!)

파일을 열어 **11번째 줄 아래**에서 찾아야 할 줄:

```js
// 현재 (잘못된 값):
const GITHUB_USERNAME = 'https://github.com/linksat1/AI-SW-Basic';

// 수정 방법 — URL이 아니라 GitHub 아이디(닉네임)만 입력:
const GITHUB_USERNAME = '본인GitHub아이디';
```

> **예시**: GitHub 프로필 주소가 `https://github.com/hong123` 이면
> `const GITHUB_USERNAME = 'hong123';` 으로 입력합니다.

---

### 3-2. `js/main.js` — 타이핑 텍스트 수정

```js
// 현재:
const texts = ['홍길동', 'Web Developer', '열정적인 개발자'];

// 수정 — 첫 번째 항목을 본인 이름으로:
const texts = ['본인이름', 'Web Developer', '열정적인 개발자'];
```

### 3-4. 프로필 사진 교체

1. 본인 사진 파일을 준비합니다 (jpg 또는 png)
2. 파일명을 `profile.jpg`로 변경합니다
3. `portfolio/images/` 폴더에 넣습니다 (기존 파일 덮어쓰기)

> **사진이 없다면**: 임시로 인터넷에서 무료 프로필 이미지를 다운로드하거나,
> `index.html`의 `src="images/profile.jpg"` 를 적당한 placeholder 이미지 URL로 바꿔도 됩니다.

## 4. 브라우저에서 실행하기

1. VS Code에서 `portfolio` 폴더를 열기
   - File → Open Folder → `AI-SW-Basic-1/b4-1/portfolio` 선택

2. 왼쪽 파일 목록에서 `index.html` 클릭

3. VS Code 오른쪽 하단의 **Go Live** 버튼 클릭
   - 버튼이 안 보이면: 상단 메뉴 View → Command Palette → `Live Server: Open with Live Server` 검색

4. 브라우저에서 `http://127.0.0.1:5500` 자동으로 열림

5. 이후 파일을 수정하면 브라우저가 **자동으로 새로고침** 됩니다.

## 5. 기능 확인 체크리스트

브라우저에서 실행 후 아래 항목을 하나씩 확인하세요.

### 기본 표시
- [ ] Hero 섹션에서 이름이 한 글자씩 타이핑되어 나타난다
- [ ] 프로필 사진이 정상 표시된다
- [ ] 네비게이션 메뉴 클릭 시 해당 섹션으로 부드럽게 이동한다

### 스크롤 동작
- [ ] 아래로 60px 이상 스크롤하면 헤더 배경색이 변한다
- [ ] 아래로 300px 이상 스크롤하면 우측 하단에 ↑ 버튼이 나타난다
- [ ] ↑ 버튼을 클릭하면 페이지 맨 위로 이동한다
- [ ] 각 섹션이 화면에 들어올 때 서서히 나타나는 애니메이션이 작동한다

### 다크 모드
- [ ] 오른쪽 상단 달 아이콘 클릭 시 다크 모드로 전환된다
- [ ] 다크 모드에서 새로고침해도 다크 모드가 유지된다

### 모바일 반응형 (브라우저 개발자 도구에서 확인)
1. F12 또는 Cmd+Option+I 키를 눌러 개발자 도구 열기
2. 상단의 폰/태블릿 아이콘 클릭 (Toggle Device Toolbar)
3. 기기를 `iPhone SE` 또는 `375px` 너비로 설정
- [ ] 네비게이션 메뉴가 숨겨지고 ☰ 햄버거 버튼이 나타난다
- [ ] ☰ 버튼 클릭 시 메뉴가 펼쳐진다
- [ ] 메뉴 항목 클릭 시 메뉴가 닫힌다
- [ ] Projects 카드가 1열로 표시된다

### GitHub API 연동
- [ ] Projects 섹션에서 잠깐 "로딩 중..." 메시지가 표시된다
- [ ] 내 GitHub 저장소 목록이 카드 형태로 표시된다
- [ ] 각 카드의 저장소 이름을 클릭하면 GitHub 페이지로 이동한다

> **저장소가 없거나 잘못된 아이디라면**: "프로젝트를 불러올 수 없습니다" 에러가 표시됩니다.
> GitHub 아이디가 올바른지 확인하고, 저장소가 Public인지 확인하세요.

### 폼 유효성 검사
- [ ] Contact 섹션에서 이름을 비워두고 전송 클릭 시 "필수 항목입니다" 에러가 나타난다
- [ ] 이메일 형식이 잘못된 경우 (예: `abc@`) 에러가 나타난다
- [ ] 메시지를 10자 미만으로 입력하고 전송 시 에러가 나타난다
- [ ] 모든 항목을 올바르게 입력하면 "전송 성공" 메시지가 나타난다

## 6. GitHub Pages 배포

### 6-1. GitHub 저장소에 파일 올리기

터미널을 열고 아래 명령어를 순서대로 실행합니다:

```bash
# 1. portfolio 폴더로 이동
cd ~/AI-SW-Basic-1/b4-1/portfolio

# 2. git 초기화 (처음 한 번만)
git init

# 3. 파일 전체 추가
git add .

# 4. 첫 커밋
git commit -m "포트폴리오 초기 업로드"
```

GitHub에 새 저장소를 만들고:
```bash
# 5. 원격 저장소 연결 (YOUR_USERNAME, YOUR_REPO_NAME을 실제 값으로 변경)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# 6. 업로드
git push -u origin main
```

### 6-2. GitHub Pages 설정

1. GitHub에서 해당 저장소 페이지 접속
2. 상단 탭에서 **Settings** 클릭
3. 왼쪽 메뉴에서 **Pages** 클릭
4. **Branch** 드롭다운에서 `main` 선택
5. 폴더는 `/ (root)` 선택 (portfolio 폴더 안의 파일을 올렸다면 root)
6. **Save** 클릭

### 6-3. 배포 URL 확인

1~2분 후 같은 Pages 페이지를 새로고침하면 URL이 나타납니다:
```
https://YOUR_USERNAME.github.io/YOUR_REPO_NAME
```

> **주의**: 배포 URL에서 GitHub API가 동작하지 않는 것처럼 보이면
> 브라우저 콘솔(F12 → Console)에서 에러 메시지를 확인하세요.

## 7. 자주 발생하는 문제 해결

### "프로젝트를 불러올 수 없습니다" 에러

**원인 1**: GitHub 사용자명이 잘못 설정됨
```js
// 잘못된 예 (URL을 넣으면 안 됨):
const GITHUB_USERNAME = 'https://github.com/linksat1';

// 올바른 예 (아이디만):
const GITHUB_USERNAME = 'linksat1';
```

**원인 2**: GitHub API Rate Limit 초과 (짧은 시간 내 60회 이상 요청)
- 1시간 기다리거나, 개발자 도구 Network 탭에서 응답 상태 코드가 `403`인지 확인
- 로컬 개발 중에는 새로고침을 너무 자주 하지 마세요

**원인 3**: GitHub 저장소가 모두 Private 상태
- GitHub에서 저장소를 Public으로 변경해야 API에서 보입니다

---

### 프로필 사진이 나타나지 않음

- `images/profile.jpg` 파일이 존재하는지 확인
- 파일명 대소문자 확인 (`profile.jpg` vs `Profile.jpg`)
- 개발자 도구 Network 탭에서 이미지 로드 실패 여부 확인 (404 에러인지)

---

### 다크 모드가 새로고침 후 초기화됨

- `js/main.js` 파일이 `index.html`에 올바르게 연결되어 있는지 확인
- 개발자 도구 Application 탭 → Local Storage에 `theme` 키가 저장되는지 확인

---

### Live Server 버튼이 안 보임

- `index.html` 파일이 선택된 상태인지 확인
- VS Code를 재시작
- Live Server 확장이 설치되어 있는지 Extensions에서 재확인

---

### 햄버거 메뉴가 동작하지 않음

- 브라우저 개발자 도구 Console 탭에서 빨간색 에러 메시지 확인
- `js/main.js`의 `const GITHUB_USERNAME` 값이 올바른지 확인
  (오류가 있으면 JS 전체가 중단되어 햄버거 메뉴도 동작 안 할 수 있음)

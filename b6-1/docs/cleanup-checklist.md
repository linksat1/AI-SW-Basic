# B6-1 리소스 정리 체크리스트 [템플릿 — 실습 종료 후 실제로 삭제하며 체크할 것]

> ⚠️ 이 체크리스트는 미리 채워진 "완료" 상태가 아닙니다. 실습이 끝난 뒤 아래 순서대로
> **실제로 AWS 콘솔에서 삭제/종료**하면서 하나씩 체크(`[x]`)하세요. 순서가 중요한 이유는
> 리소스 간 의존 관계 때문입니다(예: EIP가 인스턴스에 연결된 상태로는 일부 작업이 막히고,
> IGW는 VPC에서 분리해야 VPC를 지울 수 있습니다).

## 삭제 순서 (권장)

1. [ ] **EC2 인스턴스 종료(Terminate)** — 인스턴스 선택 → 인스턴스 상태 → 인스턴스 종료
       - 확인: 인스턴스 상태가 `terminated`로 표시됨
       - 종료 일시: \<작성\>
2. [ ] **EBS 볼륨 삭제 확인** — EC2 종료 시 "종료 시 삭제(Delete on Termination)"가
       켜져 있었다면 자동 삭제되지만, 반드시 EBS → 볼륨 목록에서 남은 볼륨이 없는지 확인
       - 확인: 볼륨 목록에 `available` 상태로 남은 미사용 볼륨 없음
3. [ ] **Elastic IP 릴리스(Release)** — 별도로 EIP를 할당했다면(자동 할당 퍼블릭 IP만
       썼다면 해당 없음) EC2 → 탄력적 IP → 연결 해제 후 릴리스
       - 해당 없음 여부: \<자동 할당만 사용했다면 "해당 없음"으로 표시\>
4. [ ] **(생성했다면) NAT Gateway 삭제** — 이 과제는 NAT Gateway가 필수 요구사항은
       아니므로 대부분 "해당 없음"
5. [ ] **(생성했다면) ELB/ALB 삭제** — 이 과제는 로드밸런서가 필수 요구사항은 아니므로
       대부분 "해당 없음"
6. [ ] **(생성했다면) RDS 삭제** — 이 과제는 RDS를 다루지 않으므로 "해당 없음"
7. [ ] **Internet Gateway 분리(Detach) 및 삭제** — VPC 콘솔 → 인터넷 게이트웨이 →
       VPC에서 분리 → 삭제
8. [ ] **Subnet 삭제** — VPC 콘솔 → 서브넷 → 삭제
9. [ ] **Route Table 삭제** — 기본 라우트 테이블이 아니라 직접 만든 것만 삭제 대상
10. [ ] **Security Group 삭제** — EC2 콘솔 → 보안 그룹 → 삭제 (기본 보안 그룹은 삭제 불가,
       직접 만든 `b6-1-web-sg`만 대상)
11. [ ] **VPC 삭제** — 위 하위 리소스가 모두 정리된 뒤에만 삭제 가능
12. [ ] **키 페어 정리(선택)** — EC2 콘솔 → 키 페어 → 더 이상 안 쓸 키 삭제(로컬 `.pem`
       파일도 필요 없으면 안전하게 보관하거나 폐기)

## 왜 이 순서와 확인이 중요한가 (평가 질문 대비)

클라우드는 "만들 때"가 아니라 **"켜져 있는 동안"** 과금됩니다. EC2 인스턴스를 콘솔에서
닫기(브라우저 탭을 닫는 것)만 해서는 리소스가 전혀 정리되지 않고, 프리 티어 한도를 넘긴
채 계속 요금이 쌓일 수 있습니다. 특히 **Elastic IP는 인스턴스에 연결되어 있지 않은 상태로
할당만 되어 있으면 별도로 과금**되고, **EBS 볼륨은 인스턴스를 종료해도 "종료 시 삭제"
옵션을 안 켰다면 볼륨만 남아 계속 과금**됩니다. 그래서 이 체크리스트는 "삭제했다고
생각되는 것"이 아니라 "콘솔에서 실제로 상태를 확인한 것"만 체크하도록 구성했습니다.

## 5. 보안 그룹 요구사항 — 반드시 콘솔에서 규칙을 직접 재확인

- [x] 인바운드에 HTTP(80) / TCP / 소스 `0.0.0.0/0` 규칙 존재
- [x] 인바운드에 SSH(22) / TCP / 소스가 `0.0.0.0/0`이 **아니라** 본인 IP `212.102.51.72/32`인지 확인
